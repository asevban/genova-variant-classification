- `final/models/artifacts/*.joblib`: RandomForest final repeat modelleri.
- `final/models/artifacts/id3_repeat_*.json`: ID3 final repeat modelleri.

- `final/SHA256SUMS.txt`: final artefakt hash kaydi.

- `archive/`: onceki layout ve teslim disi yardimcilar.
- `test/`: kullanici test CSV konumu.
- `output/`: tahmin, audit ve drift ciktisi konumu.
